# 株価取得プログラム（yfinance）

`yfinance` ライブラリを使って、日本株・米国株の最新株価や過去の株価データを取得・表示するシンプルなPythonプログラムです。

## 1. 必要なライブラリのインストール

ターミナル（コマンドプロンプト）で以下を実行してください。

```bash
pip install yfinance
```

または、このリポジトリの `requirements.txt` を使ってまとめてインストールすることもできます。

```bash
pip install -r requirements.txt
```

## 2. プログラムの実行方法

```bash
python stock_price.py
```

実行すると、以下のように入力例のヒントが表示され、銘柄コードを入力できるようになります。

```
========================================
株価チェックプログラム
========================================
調べたい銘柄のコードを入力してください。

【入力例】
  日本株：トヨタ自動車 → 7203.T　／　ソニーグループ → 6758.T
  米国株：Apple → AAPL　／　テスラ → TSLA
  ※日本株は証券コードの後ろに「.T」を付けてください
  ※何も入力せず Enter を押すと終了します
----------------------------------------
調べたい銘柄のコードを入力してください： 7203.T
```

銘柄コードを入力して Enter を押すと、最新1日分の株価が次のような日本語のテキストで表示されます。

```
---------
【銘柄】トヨタ自動車 (7203.T)
【日付】2026年9月2日
【始値】2,850円
【高値】2,880円
【安値】2,830円
【終値（現在の株価）】2,865円
【前日比】+15円 (+0.5%)
---------
```

日本株には自動で「円」、米国株には自動で「ドル」の単位が付きます。表示のあとはそのまま次の銘柄コードを続けて入力でき、何も入力せず Enter を押すとプログラムが終了します。

## 3. コードの解説

### 銘柄コードについて

- 日本株: 証券コードの末尾に `.T` をつけます（例: トヨタ自動車 `7203.T`）
- 米国株: そのままティッカーシンボルを使います（例: Apple `AAPL`）

### `show_stock_summary(ticker_symbol)`

```python
history = ticker.history(period="5d")
latest = history.iloc[-1]
previous_close = history.iloc[-2]["Close"]
```

- 前日比を計算するために直近5日分のデータを取得し、最新の1日分（`iloc[-1]`）とその前日分（`iloc[-2]`）を使います。
- 始値・高値・安値・終値をそれぞれ取り出し、`format_amount()` で単位付きの文字列（例: `2,865円`）に整形します。
- 終値と前日の終値の差から前日比の金額・パーセンテージを計算し、`format_diff()` で符号付き（`+`/`-`）の文字列にします。

### 会社名・単位の自動判定

```python
COMPANY_NAMES = {"7203.T": "トヨタ自動車", "AAPL": "Apple", ...}
CURRENCY_UNITS = {"JPY": "円", "USD": "ドル"}
```

- `COMPANY_NAMES` に登録されている銘柄は日本語の会社名で表示されます。登録がない銘柄は yfinance から取得した英語名がそのまま使われます。
- 通貨コード（`JPY`, `USD` など）から自動で「円」「ドル」の単位を判定して表示します。

### キーボード入力の仕組み

```python
ticker_symbol = input("調べたい銘柄のコードを入力してください： ").strip()
if not ticker_symbol:
    break
show_stock_summary(ticker_symbol.upper())
```

- `input()` でキーボードからの入力を受け取り、前後の余計な空白を `.strip()` で取り除きます。
- 何も入力せず Enter だけ押した場合はループを抜けてプログラムを終了します。
- 入力された文字を `.upper()` で大文字に変換してから検索するので、`aapl` のように小文字で入力しても問題ありません。
- 存在しない銘柄コードを入力した場合や通信エラーが起きた場合も、エラーメッセージを表示してプログラムは終了せず、続けて別の銘柄コードを入力できます。

## 4. カスタマイズ方法

`COMPANY_NAMES` に登録されていない銘柄コードを入力した場合は、日本語名ではなく英語の会社名で表示されます。日本語名で表示したい場合は、`stock_price.py` 内の `COMPANY_NAMES` に `"銘柄コード": "日本語の会社名"` を追加してください。

```python
COMPANY_NAMES = {
    "7203.T": "トヨタ自動車",
    "TSLA": "テスラ",  # ここに好きな銘柄を追加できます
    ...
}
```

## 5. 注意事項

- `yfinance` はYahoo! Financeのデータを利用しています。取得できるデータの正確性・リアルタイム性は保証されないため、参考情報としてご利用ください。
- インターネット接続が必要です。
- 短時間に大量のリクエストを送ると、一時的にデータが取得できなくなる場合があります。
