# 株価取得プログラム（yfinance + Yahoo Finance検索）

企業名（日本語・英語どちらでもOK）を入力するだけで、日本株・米国株の最新株価を分かりやすい日本語のテキストで表示するPythonプログラムです。
銘柄コード（ティッカー）を自分で調べる必要はありません。

## 1. 必要なライブラリのインストール

ターミナル（コマンドプロンプト）で以下を実行してください。

```bash
pip install yfinance requests
```

または、このリポジトリの `requirements.txt` を使ってまとめてインストールすることもできます。

```bash
pip install -r requirements.txt
```

## 2. プログラムの実行方法

```bash
python stock_price.py
```

実行すると、以下のように入力例のヒントが表示され、企業名を入力できるようになります。

```
========================================
株価チェックプログラム
========================================
調べたい企業名を入力してください。

【入力例】
  日本語：トヨタ　／　ソニー　／　ソフトバンク
  英語　：Apple　／　Tesla　／　Microsoft
  ※7203.T や AAPL のように銘柄コードを直接入力してもOKです
  ※何も入力せず Enter を押すと終了します
----------------------------------------
調べたい企業名を入力してください： トヨタ
```

企業名を入力して Enter を押すと、自動で銘柄コードが見つかり、最新1日分の株価が次のような日本語のテキストで表示されます。

```
→「トヨタ」から銘柄コード「7203.T」を見つけました。
---------
【銘柄】トヨタ自動車 (7203.T)
【日付】2026年9月2日
【始値】2,850円
【高値】2,880円
【安値】2,830円
【終値（現在の株価）】2,865円
【前日比】+15円 (+0.5%)
---------
```

日本株には自動で「円」、米国株には自動で「ドル」の単位が付きます。表示のあとはそのまま次の企業名を続けて入力でき、何も入力せず Enter を押すとプログラムが終了します。

## 3. コードの解説

### 全体の流れ

1. `search_ticker()` … 入力された企業名を Yahoo Finance の検索API（`https://query2.finance.yahoo.com/v1/finance/search`）に問い合わせて、該当する銘柄コードを見つける
2. `show_stock_summary()` … 見つかった銘柄コードを使って `yfinance` から株価データを取得し、日本語のテキストで表示する
3. `lookup_and_show()` … 上記1と2をつなげて、一連の処理を行う

### `search_ticker(keyword)`

```python
params = {"q": keyword, "quotesCount": 5, "newsCount": 0}
response = requests.get(SEARCH_URL, params=params, headers=REQUEST_HEADERS, timeout=10)
quotes = response.json().get("quotes", [])
equities = [q for q in quotes if q.get("quoteType") == "EQUITY"]
```

- `requests` ライブラリでYahoo Financeの検索APIを呼び出し、企業名に一致する候補一覧（`quotes`）を取得します。
- 検索結果には株式以外（指数など）も含まれることがあるため、`quoteType` が `"EQUITY"`（株式）のものを優先して選びます。
- 見つかった候補の中から最初の1件（`symbol`＝銘柄コード）を採用します。

### `show_stock_summary(ticker_symbol, search_name)`

```python
history = ticker.history(period="5d")
latest = history.iloc[-1]
previous_close = history.iloc[-2]["Close"]
```

- 前日比を計算するために直近5日分のデータを取得し、最新の1日分（`iloc[-1]`）とその前日分（`iloc[-2]`）を使います。
- 始値・高値・安値・終値をそれぞれ取り出し、`format_amount()` で単位付きの文字列（例: `2,865円`）に整形します。
- 終値と前日の終値の差から前日比の金額・パーセンテージを計算し、`format_diff()` で符号付き（`+`/`-`）の文字列にします。

### 会社名・単位の自動判定

```python
COMPANY_NAMES = {"7203.T": "トヨタ自動車", "AAPL": "Apple", ...}
CURRENCY_UNITS = {"JPY": "円", "USD": "ドル"}
```

- `COMPANY_NAMES` に登録されている銘柄は日本語の会社名で表示されます。
- 未登録の銘柄は、Yahoo Financeの検索結果に含まれる会社名（英語）を表示します。
- 通貨コード（`JPY`, `USD` など）から自動で「円」「ドル」の単位を判定して表示します。

## 4. カスタマイズ方法

`COMPANY_NAMES` に登録されていない銘柄コードの場合は、日本語名ではなく英語の会社名で表示されます。日本語名で表示したい場合は、`stock_price.py` 内の `COMPANY_NAMES` に `"銘柄コード": "日本語の会社名"` を追加してください。

```python
COMPANY_NAMES = {
    "7203.T": "トヨタ自動車",
    "6501.T": "日立製作所",  # ここに好きな銘柄を追加できます
    ...
}
```

## 5. 注意事項

- `yfinance` および企業名検索はYahoo! Financeのサービスを利用しています。取得できるデータの正確性・リアルタイム性は保証されないため、参考情報としてご利用ください。
- インターネット接続が必要です。
- 短時間に大量のリクエストを送ると、一時的にデータが取得できなくなる場合があります。
- 企業名があいまいだと、意図しない銘柄がヒットすることがあります。その場合は正式な会社名や、英語名、あるいは銘柄コード（例: `7203.T`, `AAPL`）を直接入力してみてください。
